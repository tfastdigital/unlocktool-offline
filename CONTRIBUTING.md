# Contributing

We welcome technicians, developers and device specialists who want to help improve UnlockTool Offline. Useful contributions include documentation corrections, reproducible installation reports, verified device information, model requests and proposals for additional authorised operations, device support and loaders.

Use the supplied issue forms. Remove personal and device identifiers before attaching screenshots or logs. A model request should contain only the public brand/model name, chipset when known, Android/security-patch version, connection mode and requested operation.

Do not submit proprietary payloads, loaders, credentials, licence material, customer data or extracted application source to this public repository. If you have code, a loader, a payload or another private technical contribution, contact TFast Digital Agency before sending any file:

Sending a proposal does not guarantee inclusion. Technical material must be lawful to share, reviewed for ownership and licensing, checked for malware, matched to the correct hardware and validated before release.
