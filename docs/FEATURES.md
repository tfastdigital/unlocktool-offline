# Features

## Desktop application

- Multi-brand and chipset-organised workflows.
- USB, COM, ADB, Fastboot, EDL, BROM, META, sideload and supported Unisoc connection modes.
- Detailed device-information output when the connected interface exposes it.
- Model-dependent flash, readback, backup, reset and recovery workflows.
- Driver, missing-data, model and loader-mismatch reporting.
- Per-operation logs stored under the UnlockTool output folders.
- Destructive-operation warnings and model/connection checks.

## Distribution and updates

- Windows 10/11 64-bit package with bundled managed runtime dependencies.
- Branded multipart extractor with archive and free-space checks.
- SHA-256 release verification.
- Application-only updates when payload data has not changed.
- Full setup and payload releases when payload data changes.

## Licensing and support

- Telegram-assisted Gmail registration and one-PC licence binding.
- User and administrator activation notifications.
- Official release-channel membership checks for free access.
- User log submission and administrator diagnostic reports.

Feature availability depends on the exact model, chipset, firmware/security patch, connection mode, required helper and payload status. See [supported operations](SUPPORTED-OPERATIONS.md) before making a customer-facing claim.
