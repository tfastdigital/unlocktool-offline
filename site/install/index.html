Install and activate

  1. Download all eight archive parts, the branded extractor and checksum file.
  2. Keep every file in one folder and verify SHA-256 values.
  3. Finish device operations and close any older UnlockTool window.
  4. Run the branded extractor, then run setup from the extracted package.
  5. Open the licence bot, join the release channel and send your own Gmail address.
  6. Enter the one-use code and the same Gmail address in the application.
Do not rename individual archive parts. Existing users should preserve their licence and logs during an app update.
